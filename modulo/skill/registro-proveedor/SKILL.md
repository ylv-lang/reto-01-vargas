---
name: registro-proveedor
description: Conocimiento de proceso para preparar formularios y soportes de registro de proveedores.
---
1. Leer solicitud y plantilla.
2. Mapear etiquetas mediante glosario y maestro.
3. Clasificar cada campo como lleno, faltante o requiere confirmación.
4. Generar Excel/PDF o valores Markdown para portal.
5. Copiar soportes existentes y marcar ausentes/vencidos.
6. Preparar checklist y borrador de correo.
7. Solicitar revisión humana; nunca firmar ni enviar realmente.
